# AI-Native Blog API Project

## Commands
- Build: npm run build
- Test: npm test
- Lint: npm run lint

## Conventions
- Node.js / Express / JavaScript (ES Module)
- Every endpoint requires authentication header check (mock JWT)
- Input validation required using schema validation.

## Architecture
- src/routes/ holds REST endpoints
- src/models/ holds data schemas/models
- intent/, specs/, plans/ hold the AI-Native SDLC phase artifacts.
